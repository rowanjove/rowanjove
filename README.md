## 关于我

喜欢研究 AI、游戏、系统与网络底层，热衷于把脑子里那些“不如做出来试试”的想法敲成能够稳定运行的实体工具。

目前主要专注于独立开发、本地优先（Local-First）桌面应用、多 Agent 协作工作流、Windows 网络实用程序与 Cloudflare 边缘计算。
